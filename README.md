# SafeTox AI

**AI-Powered Toxic Gas Monitoring and Sewage Worker Safety System**

SafeTox AI is a safety-focused project designed to support toxic gas monitoring and risk awareness in sewage environments. The project aims to improve worker safety through sensor-based monitoring, alerts, and intelligent risk assessment.

## Live Demo

[**View SafeTox AI Demo**](https://safe-tox-ai-m3zhpdlf46k3k9oxub6bwn.streamlit.app/)

## Technology Stack

- Python
- AI / Machine Learning
- IoT Sensors
- ESP32
- Dashboard and Alert System

## Project Files

- `app.py` — Main application file.

## Project Objective

To support safer sewage operations by identifying potential toxic gas risks and providing timely safety alerts.

## Disclaimer

This project is intended as a prototype. It should not be used as the sole basis for real-world confined-space entry or worker safety decisions.
